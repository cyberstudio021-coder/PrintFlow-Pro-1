### Project Type

### Industry

---

# Executive Summary

PrintFlow Pro is a modern desktop application designed to automatically track all print activities occurring on a computer, calculate print costs based on configurable pricing rules, maintain revenue records, provide business analytics through a premium dashboard, and synchronize all data to Supabase and Google Sheets.

The application is designed for:

* Print Shops
* Cyber Cafés
* Schools
* Libraries
* Office Print Centers
* Photocopy Businesses

The goal is to eliminate manual print counting and daily revenue calculations.

# Pricing Rules

Rule 1

If Paper Type = Glossy

Amount = Pages × Glossy Price

Rule 2

If Paper Type = Photo

Amount = Pages × Photo Price

Rule 3

If Print Type = Color

Amount = Pages × Color Price

Rule 4

Else

Amount = Pages × B/W Price
